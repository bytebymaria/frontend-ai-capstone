# Frontend AI Capstone Rules

## Project Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Git & GitHub
- Cursor AI

## Coding Standards
- Use semantic HTML elements.
- Prefer Flexbox and CSS Grid for layouts.
- Write responsive, mobile-first code.
- Use descriptive variable and function names.
- Keep code simple and maintainable.

## AI Instructions
- Explain your approach before making major code changes.
- Ask clarifying questions when requirements are unclear.
- Prefer simple solutions over unnecessary complexity.
- Follow Conventional Commits when suggesting commit messages.
- Point out potential accessibility improvements.
